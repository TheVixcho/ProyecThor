# ProyecThor — Rama de Extensiones y Plugins

Esta rama está dedicada exclusivamente al desarrollo, mantenimiento y publicación de extensiones y plugins oficiales y de la comunidad para **ProyecThor**.

## Estructura
- `plugins/` — Extensiones listas para integrar en ProyecThor (ej. `ytdlp/`).

## Flujo de ramas del proyecto
- `main` — Código fuente estable de ProyecThor (C++ / OpenGL / libmpv / ImGui).
- `beta` — Desarrollo activo y pruebas previas a release.
- `web` — Sitio web oficial y GitHub Pages.
- `extensions` — Desarrollo exclusivo de extensiones y plugins.
